## 2. 商店（两段式经济：解锁价 + 单价）

### 2.1 经济模型（本设计的核心约定）

| 商品类型 | 解锁方式 | 单价（每次使用/购买） | 原版依据 |
| --- | --- | --- | --- |
| **种子** | **无解锁费**——耕种 Lv2/4/6/8/10 自动解锁一档（档位按**收获物价**升序，全表 §6.5） | 种子买价 = `Objects.Price × 2` | SeedShop `DefaultMarkup: Multiply 2`（Data/Shops.json）；原版上架条件为季节/年份（`Condition` 字段），本插件换算为等级档位，季节作为参考标签展示 |
| **建筑** | ——（直接购买，含材料，见 §3） | —— | BUILDING_CATALOG（G3 已有）+ **BuildMaterials 材料清单**（§6.2，新增材料消耗） |
| **动物** | ——（直接购买，需先拥有对应建筑，见 §4.2） | PurchasePrice 一次性 | Data/FarmAnimals.json `House` + `PurchasePrice`（§6.3） |

- ~~种子解锁价~~ **已废除**（2026-10-03 修订：按耕种等级自动解锁，不收一次性费用）。
- **购买种子消耗金币并获得一次"种植额度"**（打卡页新建习惯时选择；库存
  `profile.seeds: Record<seedId, number>`——每次种植扣 1。与现行为差异：G3 是
  "等级达标即可选"，本设计改为"等级达标 + 每次种植买种子"两段）。
- 兼容：已存在的习惯不受种子库存约束（存量习惯照常打卡）；仅新建/补种消耗种子。

### 2.2 商店页结构

```
商店（标签页）
  ├─ [种子]    网格卡：头像(收获物图标) 名/卖价 ｜状态：已解锁(价格+购买按钮)/解锁价+解锁按钮
  ├─ [建筑]    网格卡：建筑图 名/价 ｜金币 + 材料清单（够则可购，见 §3.3）
  └─ [动物]    网格卡：商店图标(ShopSourceRect) 名/价 ｜要求：对应建筑已购+已摆放（§4.2）
```

## 3. 材料系统（打卡产出 → 建造消耗）

### 3.1 产出规则（每次打卡，按技能；数值为设计初值，常量集中 `game.ts`）

| 技能 | 保底产出 | 概率产出（约 35%） | 原版获取途径对照 |
| --- | --- | --- | --- |
| 采矿 | 石头 ×2 | 煤 ×1 / 铜矿 ×1 / 铁矿 ×1 | 破碎矿石 |
| 采集 | 木材 ×2 | 硬木 ×1 / 纤维 ×2 | 砍树/采集 |
| 耕种 | 粘土 ×1（锄地） | 木材 ×1 | 锄地/清理农场 |
| 钓鱼 | —（鱼已入仓库） | 粘土 ×1 / 海藻 ×1 | 钓上杂物 |
| 战斗 | 煤 ×1 | 精炼石英 ×1 | 怪物掉落 |

- 材料入**仓库**（§4.1），物品元数据（名/卖价/图标 SpriteIndex）来自 Objects.json，
  由派生脚本固化（同 cropPrize 模式，§6.1）。
- 金币经济不变：打卡照旧得经验与出货金币；材料是**额外产出**，用于建造。

### 3.2 建筑的材料清单（原版 BuildMaterials，权威全表见 §6.2）

商店购买建筑时需同时满足 **金币 + 材料库存**（例如鸡舍 = 300 木材 + 100 石头）。
清单由派生脚本从 `Data/Buildings.json.BuildMaterials` 固化（id → 名/图标，§6.1）。

### 3.3 库存与扣减

- `profile.materials: Record<itemId, number>`；购买建筑时逐项扣减，不足则按钮
  置灰并列出缺口（如"木材 180/300"）。
- 仓库页显示材料区（与收获物区分开）。

## 4. 仓库与动物

### 4.1 仓库页

- **收获物区**：打卡收获不再直接变金币——作物入仓库
  （`profile.warehouse: Record<itemId, number>`），仓库页可按原版卖价**出售**换金币
  （保留"出货"语义，批量卖/单卖均可）。成熟丰收的 ×3 奖励改为等值金币直接入账
  （不加仓库，避免"3 个同物"分裂计数——实现细节可调）。
- **材料区**：§3.2。
- **动物区**：§4.2。

### 4.2 动物饲养（原版绑定关系）

- 前置：**对应建筑已购买且已摆放在农场**（`House` 字段权威绑定，§6.3）：
  鸡/鸭/兔 → Coop（鸡舍及其升级），牛/羊/猪 → Barn（畜棚及其升级）。
- 购买：花 PurchasePrice 金币 → 入 `profile.animals: {type, breed}[]` → 显示在
  农场摆放页对应建筑旁（动物贴图已内联，图鉴 Animals 页同源）。
- 每日打卡联动（后续迭代）：养了动物后，打卡时动物产出（蛋/奶）入仓库。

## 5. 农场摆放页（网格式，参考 stardew-valley-designer）

### 5.1 参考项目模型（`refer/stardew-valley-designer`，Kotlin）

| designer 概念 | 文件 | 映射到本插件 |
| --- | --- | --- |
| `Layout(type, area: Rect, disallowed…)` | `engine/layout/Layout.kt` | 农场网格区域（初始 16×10 tile，存档可扩） |
| `PlacedEntity(entity, place: Coordinate)`，`coordinates = place × size` | `engine/layer/PlacedEntity.kt` | 已摆放建筑：`{type, x, y}`，占格 = Buildings.json `Size` |
| `PlacedEntity.respects(layout)`：在区域内 + 类型允许 + 不冲突 | 同上 | 放置合法性校验 |
| tile 网格渲染 | editor 组件 | CSS grid + 建筑整图按 tile 尺寸缩放 |

### 5.2 设计

- **网格**：初始 16×10 格（每格 = 1 游戏 tile，显示 48px）；存档
  `profile.farmLayout = { w, h, placed: [{type, x, y}] }`。
- **建筑占格** = `Data/Buildings.json.Size`（权威：鸡舍 6×3、畜棚 7×4、筒仓 3×3、
  磨坊 4×2、鱼塘 5×5、温室 7×6、出货箱 2×1……全表 §6.4）。
- **放置交互（简版，M1）**：下方"已购未摆放"建筑托盘 → 点击选中 → 网格上悬停显示
  占格预览（绿=可放/红=冲突）→ 点击放置；点击已放置建筑 → 收回托盘。拖拽为二期。
- **校验**：区域内 + 占格不重叠（参考 `respects` 逻辑，一维化：`x<cx+w && y<cy+h`
  的格子集合求交）。
- **渲染**：建筑整图（sprites 已内联的原文件）按 `Size` 拉伸至格数 × 48px；
  农夫化身可摆放在任意空格（复用捏人 dataURL，二期）。
- **动物展示**：§4.2 购买的动物画在其建筑旁（偏移 tile，二期）。

## 7. 实施分期

- **S1 商店 + 材料**：材料产出（打卡挂接）→ 仓库数据结构 → 商店页（种子/建筑含材料）
  → 打卡页移除 farmMilestones → 首页文案/顺序调整。
- **S2 仓库 + 动物**：仓库页三区 → 出售换金币 → 动物购买（建筑绑定）→ 动物入档。
- **S3 农场摆放**：网格 + 托盘 + 放置校验 + 存档 →（二期）拖拽/动物渲染/化身摆放。

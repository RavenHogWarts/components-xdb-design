## 一、快速上手（一分钟）

1. 打开本插件的视图（围棋练习室）；
2. 默认就是做题模式，点「下一题 →」开始第一题；
3. 按题面要求在棋盘上点击落子，落子即时判分；
4. 想换口味：顶栏切「打谱复盘」，或设置里开启 AI 讲解 / KataGo 引擎。

做题页的按钮从左到右：**◐ 查气 → ↩ 撤回 → ⟳ 重试 → 👁 看答案 → ⚡ 引擎应手 → ⚖ 引擎复核 → 🤖 AI 讲解 → 📋 提示词 → 下一题 →**（后三个引擎相关按钮只在对应场景出现）。

## 二、做题练习

### 三种练习模式（顶部选择）

| 模式 | 适合 | 行为 |
| --- | --- | --- |
| **智能推荐**（默认） | 日常刷题 | 根据你近 30 次作答动态出题：连错的巩固，连对的降频，同类型轮换 |
| **顺序练习** | 系统学习 | 按课程顺序推进；棋盘左侧的选题面板可浏览全部题目与完成状态，点击直达 |
| **错题复习** | 查漏补缺 | 只出做错/看答案过的题，并用**随机旋转镜像**出题防止背位置 |

### 做题流程

1. 题面显示在右侧面板，棋盘上按提示落子；
2. **判分规则**：沿作者收录的正解走，对手会按收录变化自动应手；实际提掉目标也算完成；走出收录之外的手进入「自由探索」（不判错，可继续推演）；
3. 走错了：**↩ 撤回**成对退回你的上一手；**⟳ 重试**整题重来；**👁 看答案**逐步演示主线（会记入复习池）；
4. **◐ 查气**：任意时刻点击棋盘上的棋子，查看整块棋与气（斜对角不算气）；「X」开启专注模式纯读棋，Esc 退出。

### 快捷键

| 键 | 作用 |
| --- | --- |
| `Z` | 撤回 |
| `N` | 下一题 |
| `H` | 提示 |
| `X` | 查气专注模式 |
| `Esc` | 清除查气显示 |

### 自由探索 + 引擎陪练

走出收录变化后（状态显示「这手走出了参考变化」）：

- **⚡ 引擎应手**：KataGo 替对手落一手最强应对，你继续接着算（不判分、不记档案）；
- **⚖ 引擎复核**：把你刚才那手与参考答案各算一遍（visits 128），显示「你的 vs 参考」的胜率/目差对比和差值结论——告诉你这手亏了多少目。

## 三、题库：内置题与导入 Go Game Guru 417 题

**内置 182 题**开箱即用：入门课程 64（救棋/提子/连接/阻断）+ 手筋训练 118（双打吃/征吃/枷吃/门吃/倒扑/接不归等）。

**导入 Go Game Guru 题库**（417 道 Weekly Go Problems，解说已全文汉化，英文原文可对照）：

1. 在本插件仓库运行 `pnpm convert-ggg`，生成 `assets/ggg-lessons.json`（约 1.1MB；仓库不含此文件，许可要求与代码分离）；
2. 设置 → 题库管理 → 「＋ 导入题库文件」→ 选择该 JSON；
3. 导入时逐题回放校验，完成后回到视图即可练习。

题库管理里**一行一个题库**：开关控制是否参与选题，✕ 删除；被停用题库的题集会显示为灰色不可选。

## 四、打谱复盘

顶栏切「打谱复盘」。

### 载入棋谱（四种方式）

| 方式 | 操作 |
| --- | --- |
| 📂 打开 SGF | 选本地 `.sgf` 文件 |
| 📁 文件夹棋谱 | **先把 SGF 集中放一个文件夹**，设置 → 打谱 → SGF 文件夹里选好目录；之后工具栏下拉直接列出全部棋谱，选中即载入，⟳ 重新扫描 |
| 📋 粘贴棋谱 | 粘贴 SGF 文本；也可填 vault 内 `.sgf` 路径读取 |
| ✦ 示例 | 内置示例棋谱，先体验用 |

### 复盘操作

- **← →** 逐手前进后退，**Home/End** 跳首末，**空格**自动播放，滑杆快速定位；
- 多分支变化用「变化」行切换；注释与标记随节点显示；
- **✎ 试下**：在任意局面落子开分支推演（蓝色描边区分），可退一手/清除，导出 SGF 时保留；
- **⚡ 分析**：引擎评估当前局面——侧栏出现黑白胜率条、目差，棋盘上 A–F 字母标出前六个候选点；点侧栏候选行可**预览该点的后续主变化**（棋盘摆出后 8 手，点棋盘退出）。每个局面只算一次，翻谱回来直接显示。

设置页顶部的两个棋盘偏好：「显示棋盘坐标」（棋盘边缘显示列字母与行号，对照讲解方便）、「打谱显示手数」（棋子上标注第几手，仅打谱模式）。

> 棋谱哪里来：自己的对局导出 SGF，或从 [katagotraining.org/games](https://katagotraining.org/games/) 下载强 AI 的自对弈棋谱放进文件夹，配「⚡ 分析」复盘涨棋。

### 人机对局

和 KataGo 下一盘完整的棋（需引擎已启动）：

1. 工具栏点「**✚ 对局**」→ 选 9 / 13 / 19 路 → 开出空棋盘，自动进入试下模式并打开「🤖 自动应手」；
2. **你执黑先行**，直接在棋盘落子；轮到引擎时它自动应手（每手随引擎性能几秒内）；
3. **想让引擎执黑**：开局先点一次「⚡ 引擎应手」，引擎落第一手并从此接管黑棋，你执白；
4. 「🤖 自动应手」可随时开关——关掉后用「⚡ 引擎应手」手动让它下每一手；
5. 下错了「↩ 退一手」悔棋（引擎和你的手都成对退）；「✕ 清除试下」回到空盘重来；
6. 下完「**⬇ 导出 SGF**」保存整盘对局（试下分支会保留），可以之后导回来复盘、配「⚡ 分析」逐手看胜率。

对局中随时可点「⚡ 分析」看当前局面评估（胜率条 + 候选点），相当于开着引擎支招下棋。

## 五、AI 讲解

把任意 OpenAI 兼容接口接入做题讲解（OpenAI / DeepSeek / Qwen / GLM / 本地 Ollama 均可）。

**配置**：设置 → AI 讲解 → 填 Base URL（如 `https://api.bigmodel.com/v1`）、API Key（密文显示）、模型名 → 「测试连接」验证。

**使用**：做题任意时刻点「🤖 AI 讲解」，生成当前局面的中文棋理讲解（Markdown 渲染，可选中复制）；「📋 提示词」把完整提示词复制到剪贴板，可粘到任何聊天模型。

- **深度思考**（默认关）：思考型模型（deepseek-reasoner / QwQ / GLM 思考链）打开它，不限时长完整推理；普通模型保持关闭更快。
- 提示词已内置程序预计算的棋块/气分析，弱模型也能讲对棋盘。

## 六、KataGo 引擎（可选，推荐）

接入 KataGo 后获得：打谱局面分析、做题引擎应手、引擎复核。三种能力共用一个引擎。

### 安装（Windows 实践路线）

本节是**实际部署成功**的路线（Win + NVIDIA 显卡）。macOS/Linux 及完整排错见 [katago-setup.md](./katago-setup.md)。

**第 0 步 · 确认显卡与驱动**：`Win+R` → `cmd` → 运行 `nvidia-smi`，看第一行的 CUDA 版本。走 TRT 版（cuda13.2）需要 ≥ 13.2（如 `CUDA Version: 13.3` 即可）；显示命令不存在说明没有 N 卡，只能用 CPU 版（见 katago-setup.md）。

**第 1 步 · 下载并解压程序**（[KataGo Releases](https://github.com/lightvector/KataGo/releases)，按版本建目录，模型也放里面）：

```
D:\Program Files (x86)\katago\
├── v1.18.1-onnx1.24.4-directml\        ← 路线 A：日常用（免依赖）
│   ├── katago.exe
│   ├── analysis_example.cfg 等
│   └── lionffen_b6c64_3x3_v10.txt.gz   ← 模型（Extra Nets 下载，小而快）
└── v1.18.1-trt10.16.1-cuda13.2\        ← 路线 B：最强（需补 DLL）
    ├── katago.exe
    ├── nvinfer_10.dll …（见第 3 步补充的 TensorRT DLL）
    └── kata1-tf3-b11c768-s11003M-d5973M-7gres.bin   ← 模型（主表最强评级）
```

**第 2 步 · 下载模型**（`.bin.gz` / `.txt.gz` 直接用，不用解压）：

| 用途 | 模型 | 下载处 | 配哪个程序 |
| --- | --- | --- | --- |
| 快、日常够用 | `lionffen_b6c64_3x3_v10.txt.gz` | Extra Nets → Strength-Finetuned | 两个都能跑 |
| 最强评估 | `kata1-tf3-b11c768-….bin` | 主表顶部「最强可靠评级」 | **只能 TRT 版** |

> ⚠ 架构匹配：`tf`/`nbt`/`npt` 后缀是 transformer，**只有 TRT/CUDA 版程序能跑**；directml（onnx）版只能跑 CNN（Lionffen 系、b60c320 等 `nbn`/无后缀老系）。配错了启动会报「不支持的网络架构」。

**第 3 步 ·（仅路线 B）补 TensorRT DLL**：TRT 版 zip 不自带 TensorRT，直接运行会弹「找不到 `nvinfer_10.dll` / `nvonnxparser_10.dll`」。补法（免开发者账号，实测可用）：

1. 下载 TensorRT 库 wheel（**版本号前两段要和程序名对上**：trt**10.16.1**-cuda13.2 ↔ **10.16.1**.11）：
   `https://pypi.nvidia.com/tensorrt-cu13-libs/tensorrt_cu13_libs-10.16.1.11-py3-none-win_amd64.whl`（约 1.9 GB）；
2. 把 `.whl` 后缀改成 `.zip` 解压（wheel 本质就是 zip）；
3. 把解压出的 `tensorrt_libs\` 目录里**全部 DLL**（`nvinfer_10.dll`、`nvonnxparser_10.dll`、`nvinfer_plugin_10.dll` 及各 `…_smXX_10.dll`）复制到 `v1.18.1-trt10.16.1-cuda13.2\` 里 katago.exe 旁边；
4. 再运行若还弹缺 `cublas`/`cudart`/`cudnn` 之类 DLL，按文件名继续补（对照 katago-setup.md FAQ）。

有 Python 的话第 1 步也可以：`pip download tensorrt-cu13-libs==10.16.1.11 --index-url https://pypi.nvidia.com --only-binary=:all: -d trt`。

**第 4 步 · 插件配置**：设置 → KataGo 引擎 →

1. 模式选「**本地引擎**」；
2. katago 路径「📁 浏览」选所用版本的 `katago.exe`（选择器限定 .exe 且校验 katago 开头）；
3. 模型路径「📁 浏览」选 `.gz`/`.bin` 模型文件；
4. 「探测版本」秒验程序可用 → 「启动引擎」→ 状态灯变绿「引擎就绪」。

**两套怎么选**：directml + b6c64 每手瞬间出，适合日常刷题；TRT + b11c768 首次启动要为显卡构建执行计划（几十秒到一两分钟，之后有缓存），换算质量最高，适合认真复盘。切换只需在设置里换两个路径再重启引擎，两套共存。

### 设置项说明

| 项 | 说明 |
| --- | --- |
| 模式 | 关闭 / 本地引擎 / 远程端点 |
| katago 路径 | 本地 katago.exe（📁 限定 .exe 且校验文件名 katago 开头） |
| 模型路径 | 神经网络文件（📁 限定 .gz） |
| ONNX 后端 | onnx 版程序才显示；默认自动按文件名推断（directml 等），一般不用动 |
| visits | 每个局面的计算量，默认 200；越大越准越慢，做死活题 200 足够 |
| 启动/停止 | 引擎是后台进程，跨视图存活；插件卸载时自动清理 |

### 顶栏状态灯

- 灰点：未启用；**黄色脉冲**：启动中（首次加载模型可能几十秒）；**绿色**：就绪；**红色**：错误（悬停看原因，stderr 会回显在设置页）；蓝色字「远程端点」：远程模式待请求。

### 远程端点模式

引擎跑在另一台机器时用：填一个 HTTP 地址（契约与 katago analysis 行协议同构，最小部署示例见 katago-setup.md「远程端点模式」节，**服务端必须回 CORS 头**），设置页可「测试连接」。

## 七、学习档案

做题页可展开「学习档案」面板：

- **概览**：独立作答统计（用过提示/答案的不计入）、正确率、复习池数量；
- **知识点掌握度**：五类技巧的正确率条形图；
- **推荐卡**：下一道题为什么推给你的策略说明；
- **近期作答**：最近 10 次记录（✓ 答对 / ✗ 答错 / ～ 待复核）。

「重置学习进度」在设置页最底部，清空后不可恢复。

## 八、数据保存在哪里

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 学习记录、AI/引擎/SGF 文件夹配置 | 浏览器 localStorage | 插件卸载/清理浏览器数据会丢失 |

## 九、常见问题

**引擎启动失败怎么办？**
设置页引擎区的红色状态行会显示引擎的报错原文。缺 DLL、配置键、onnxProvider 等安装类问题的完整对照表在 [katago-setup.md](./katago-setup.md)「常见问题」一节；实在不行换 onnx-directml 版 + CNN 模型的组合，兼容性最好。

**分析/应手很慢？**
降 visits（设置 → 200 → 50）；换更小模型（b60c320 → Lionffen b6c64）；CPU 集显机器这是常态。每个局面只算一次，翻谱不重复算。

**AI 讲解超时/报错？**
先「测试连接」；思考型模型开「深度思考」；GLM-5.3 系列不支持关思考，插件已自动处理。

**导入题库失败？**
文件需是 go-coach 原生题目数组或本插件紧凑格式（`pnpm convert-ggg` 产物）；导入时会逐题校验，失败的具体题目与原因会显示在状态行。

**引擎应手点了没反应？**
按钮会先变「⏳ 引擎思考…」，完成后有 toast 提示结果（应手坐标 / 失败原因 / 引擎建议停一手）。思考期间你自己落子不受影响，引擎会基于最新局面应手。

**快捷键不生效？**
焦点需在视图内（点一下棋盘区域）；输入框聚焦时快捷键自动失效。
